# Municipal Routing Dashboard

Полноценная демонстрационная система для построения маршрутов спецтехники по данным KML.

## Запуск

```bash
python server.py
```

Перед запуском заполните `.env` Google API ключами.

## Возможности

- Парсинг `GEO.kml` и `RoadCity.kml`
- Деление территории на сетку зон
- Автоматическое распределение дорожных сегментов по тракторам
- Интеграция со всеми основными сервисами Google Maps Platform
- Богатый интерфейс на Google Maps JS + TailwindCSS
- Экспорт маршрутов в KML и GeoJSON
